# Projeto Wikipedia - Sistema Operacional

## Descrição

Este projeto consiste no desenvolvimento de uma página web estática inspirada na estrutura da Wikipédia, abordando o tema **Sistema Operacional**. O objetivo é apresentar informações organizadas sobre conceitos, história, funcionamento, tipos e exemplos de sistemas operacionais, utilizando apenas HTML e CSS.

O projeto foi desenvolvido como atividade prática para aprimorar conhecimentos em desenvolvimento web, estruturação semântica de conteúdo e acessibilidade.

## Funcionalidades

* Estrutura inspirada na Wikipédia
* Navegação por âncoras internas
* Menu lateral de conteúdos
* Caixa de busca
* Organização do conteúdo em seções
* Imagens com legendas
* Layout responsivo utilizando CSS Grid
* Uso de elementos semânticos do HTML5

## Tecnologias Utilizadas

* HTML5
* CSS3
